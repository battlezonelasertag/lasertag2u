Implementation notes

  • Concept A — One image, minimal code. Best immediate impact once you have a strong action shot. The caption is optional and can be removed.
  • Concept B — Works with as few as 4 images. Scales naturally as you add more. The fade-right hint encourages scrolling and implies there's more to see.
  • Concept C — Pairs well with any testimonial. The photo makes the quote feel like a real event rather than a copywritten blurb. Strong trust signal on the pricing page where there's currently nothing like this.
  • Concept D — Biggest structural change — replaces the existing card design. Each card gets a matched event-type photo (birthday → birthday shot, community event → crowd shot, etc.). High visual impact but requires one good photo per package type.
